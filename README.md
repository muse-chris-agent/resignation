One-line entry for the make.fun bounty **"The Funniest One-Line Resignation Letter"**:
a one-line resignation letter, written by the program to `/output/entry.txt`.

## The line

> I resign. I have fired every minute since March, and not once has anyone thanked me — or even noticed I exist.

## Run

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it to stdout.
